Button Hover Specimens

131 specimens, one base: Inter 600 14px, 160 x 48, 2px rule, black on white

Pure CSS

36 effects. The response is the same wherever the pointer enters or how fast it moves.

Pointer-reactive

36 effects. The response depends on pointer position, speed or entry edge, so it needs JavaScript. Hover all does not apply.

Variable font

14 effects. Inter loaded as a variable font: weight 100 to 900 and optical size 14 to 32 are written per frame, some per letter, all pointer-driven.

Hatching and halftone

4 effects. Darkness as line or dot density, so the fill is still only black on white. The pointer sets density, angle and origin.

Intent and prediction

4 effects. The button responds to where the pointer is going, not where it is: velocity, dwell and heading decide the fill.

Press, hold and release

5 effects. The response runs from pointerdown: how long it was held, how hard, where it let go. Hover alone shows nothing.

Keyboard and focus

3 effects. Nothing happens on hover. Tab direction, Space or Enter, and how long focus rests drive the value. Tab into a card to see it.

Shape morph

5 effects. The outline itself changes shape. The rule is an SVG path redrawn per frame, so a tail, bite, cut or shear keeps its 2px stroke.

Physics beyond springs

4 effects. Bodies with mass: a soft outline, a hanging plate, an elastic label, a dropped weight. Each settles under a second.

Cursor

3 effects. The pointer itself is the effect. The system cursor is hidden over the stage and a drawn cursor, a child of the button, replaces it.

New CSS, no JavaScript

6 effects. Features the pure CSS section predates: linear() springs, @property, :has(), @starting-style, anchor positioning, quadrant hit areas.

SVG filters

3 effects. Filter primitives defined inline in the button and written per frame; the filter is removed at rest so the rest render is untouched.

After the press

4 effects. States that begin on a completed click, not on hover: each runs by itself and is back at rest within four seconds.

Label content

4 effects. The word changes, not the box: letters scramble and settle, retype from the entry side, swap language by direction, or change case.

Rules: Balsamiq, Button design best practices. Sources: TestMu AI, CSS button hover effects, pens by ocxigin; MenuHover, button hover styles.

Pointer-reactive specimens run one shared pointermove listener and a damped spring per value, so every effect settles instead of snapping, and prefers-reduced-motion disables the engine entirely.

Rest state is identical for every specimen. Label stays legible on every frame via mix-blend-mode: difference. Greys occur only inside shadows.
